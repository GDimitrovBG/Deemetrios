# TG Media Saver

Android приложение за Samsung (и всеки друг Android телефон с 64-битов ARM процесор),
което сваля снимки, видеа, GIF-ове и файлове от твоите Telegram чатове и канали
направо в Галерията на телефона.

Работи през **официалната библиотека TDLib**, компилирана от източника
[tdlib/td](https://github.com/tdlib/td) — влизаш с личния си Telegram акаунт
(телефонен номер + код), виждаш всичките си чатове и сваляш наведнъж колкото
файла искаш, без ограничението от 20 MB, което имат Telegram ботовете.

## Какво може

- Вход с личен Telegram акаунт (телефон, код, двустъпкова парола)
- Списък с всички чатове, групи и канали, с търсачка
- Сканиране на цялата история на чат за медия
- Филтри: снимки и видеа / само снимки / само видеа / GIF / документи
- Преглед като решетка с миниатюри, размер и дължина на видеото
- Избор поединично или „Избери всички“
- Паралелно сваляне (3 файла наведнъж) с прогрес и известие
- Записване в Галерията:
  - снимки → `Pictures/Telegram Saver`
  - видеа и GIF → `Movies/Telegram Saver`
  - документи → `Download/Telegram Saver`
- Кешът на TDLib се чисти след всеки записан файл, за да не се запълва паметта

## Инсталиране на телефона

1. Прехвърли `app-debug.apk` на телефона (USB, Google Drive, имейл до себе си).
2. Отвори файла с „Моите файлове“. Samsung ще поиска разрешение
   „Инсталиране на непознати приложения“ — разреши го за приложението, с което
   отваряш APK-то.
3. Инсталирай и отвори.

APK-то е подписано с debug ключ — достатъчно за лично ползване, но не може да
се качи в Google Play.

## Първо стартиране: api_id и api_hash

Telegram изисква всяко приложение, което влиза в акаунт, да има свои ключове.
Приложението ги иска при първото стартиране:

1. Отвори `my.telegram.org` в браузъра.
2. Влез с телефонния си номер (кодът идва като съобщение в Telegram).
3. Избери **API development tools**.
4. Създай приложение — име и платформа по избор.
5. Копирай **App api_id** и **App api_hash** в екрана за настройка.

Ключовете остават само на телефона, в private storage на приложението.

## Как да го билднеш сам

Нужни са: JDK 17+, Android SDK (platform 35, build-tools 35, NDK 27), и
`libtdjni.so`, който вече е в `app/src/main/jniLibs/arm64-v8a/`.

```bash
echo "sdk.dir=/път/до/Android/sdk" > local.properties
gradle assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

### Как беше направена нативната библиотека

`libtdjni.so` е компилирана от официалното репо на TDLib, а не взета от трета
страна — TDLib получава достъп до реалната Telegram сесия, така че чужди готови
библиотеки са излишен риск.

```bash
git clone --depth 1 https://github.com/tdlib/td
cd td/example/android
./build-openssl.sh  <SDK> 27.2.12479018 third-party/openssl OpenSSL_1_1_1w
./build-tdlib.sh    <SDK> 27.2.12479018 third-party/openssl c++_static Java 24 "arm64-v8a"
# → tdlib/libs/arm64-v8a/libtdjni.so  +  tdlib/java/org/drinkless/tdlib/*.java
```

Версия в това репо: TDLib commit `f10611ee1f03f91ddae8185483a1ccfd3d664668`,
OpenSSL 1.1.1w, NDK 27.2.12479018, minSdk 24, само `arm64-v8a`.

## Структура

| Файл | Роля |
|---|---|
| `tg/TgClient.kt` | обвивка на TDLib: стартиране, вход, заявки като coroutines |
| `tg/TgRepository.kt` | чете чатове и обхожда историята за медия |
| `tg/ThumbCache.kt` | сваля и помни миниатюрите за решетката |
| `Downloader.kt` | опашка за сваляне, 3 паралелни файла, прогрес |
| `DownloadService.kt` | foreground service, за да не спира свалянето на заден план |
| `MediaSaver.kt` | записва файла в Галерията през MediaStore |
| `MainViewModel.kt` | състояние на екраните |
| `ui/` | Compose екрани (настройка, вход, чатове, медия) |

## Ограничения

- Само `arm64-v8a`. Всеки Samsung от последните ~10 години е такъв, но много
  стар 32-битов телефон няма да я стартира.
- Няма вграден плеър — файловете се гледат в Галерията след свалянето.
- Сканирането на много голям канал отнема време, защото обхожда историята на
  страници по 100 съобщения.
- Приложението ползва твоя акаунт. Сваляй само съдържание, което имаш право да
  запазваш.
